# World-Building for Fiction

A structured workspace for developing a fictional world and the novel(s) set in it. The system is designed to keep ideas discoverable, preserve established canon, and expose contradictions without forcing a genre or magic system onto the setting.

## Start here

1. **[World Bible](WORLD_BIBLE.md)** — the high-level premise, tone, themes, and defining truths of the setting.
2. **[Canon and Open Questions](CANON.md)** — what is established, tentative, disputed, or still undecided.
3. **[Timeline](TIMELINE.md)** — major historical events and story-era chronology.
4. **[Story Threads](STORY_THREADS.md)** — conflicts, mysteries, promises, and unresolved plotlines.
5. **[Character template](templates/CHARACTER.md)** — create one file per important character.
6. **[Location template](templates/LOCATION.md)** — create one file per important place.
7. **[Culture template](templates/CULTURE.md)** — societies, institutions, customs, and internal disagreements.
8. **[World-system template](templates/WORLD_SYSTEM.md)** — magic, technology, ecology, economics, or any other system relevant to the setting.

## Working rules

- **Separate fact from possibility.** Mark uncertain ideas as *Proposed* rather than silently treating them as canon.
- **Prefer causes and consequences.** For each major rule, ask what it enables, what it prevents, who benefits, and what it costs.
- **Track provenance.** When a decision changes, record the change and its reason in the canon log.
- **Avoid premature detail.** Develop material in proportion to its importance to the story.
- **No assumed genre.** Fantasy, science fiction, historical fiction, and mixed settings can all use this structure.
- **Use stable IDs when useful.** For example: `CHR-001`, `LOC-001`, `EVT-001`, `SYS-001`. IDs are optional for minor notes but useful when entries refer to one another.

## Suggested status labels

- **Canon** — established and currently authoritative.
- **Proposed** — a candidate idea, not yet committed.
- **Open** — unresolved question.
- **Deprecated** — superseded; retained only for context.
- **In-world claim** — something a character or culture believes, which may be false.

## Adding material

Copy a relevant template into a suitable folder or create a new Markdown file. Use descriptive filenames, link related entries with relative Markdown links, and update the canon log when a decision materially changes the setting.
